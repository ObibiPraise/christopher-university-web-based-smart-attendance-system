# christopher-university-web-based-smart-attendance-system

## Project Title

Design And Implementation Of Web-Based Smart Attendance System: A Case Study Of Christopher University

## Description

This project presents the design and implementation of a web-based
smart attendance system developed to improve the efficiency, accuracy,
and accessibility of student attendance management.

## Technologies Used

- HTML
- CSS
- JavaScript
- localStorage

## System Users

- Administrator
- Lecturer
- Student

## Main Features

### Student
- Secure login
- Attendance check-in
- Attendance history
- Attendance percentage monitoring

### Lecturer
- Lecturer login
- Course management
- Start attendance sessions
- Generate attendance reports

### Administrator
- User management
- Course management
- Attendance monitoring

## Project Structure

The repository contains the complete source code for the
Web-Based Smart Attendance System.

## Case Study

Christopher University Mowe, Ogun State.
